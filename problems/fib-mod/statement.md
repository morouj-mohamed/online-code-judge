# E. Fibonacci Modulo

The Fibonacci numbers are `F(0) = 0`, `F(1) = 1`, `F(k) = F(k-1) + F(k-2)`.
Print `F(n) mod m`.

## Input
One line with two integers `n` and `m` (`0 <= n <= 10^18`, `1 <= m <= 10^9`).

## Output
One integer: `F(n) mod m`.

## Example
Input
```
10 1000
```
Output
```
55
```

## Limits
Time limit: 1 second. Memory limit: 256 MB.
